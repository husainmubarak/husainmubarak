## About Me

Hey! I'm **Husain**, a Computer Science student at **Universitas Lambung Mangkurat**, Indonesia. I enjoy turning ideas into practical software and exploring how technology can solve real-world problems.

My main interests are **AI Engineering, Machine Learning, Computer Vision, and Web Development**. I like working across the stack—from experimenting with models and data to building applications that people can actually use. I also have a visual-design background, so I enjoy combining technical problem-solving with thoughtful user experiences.

- 🎓 Studying Computer Science at Universitas Lambung Mangkurat.
- 🤖 Currently exploring AI, machine learning, and computer vision.
- 🌐 Interested in building useful web and software applications.
- 🎨 Bringing together code, visual thinking, and collaboration.
- 🚀 Personal motto: **"Coba aja dulu."** — Try first, learn along the way.
